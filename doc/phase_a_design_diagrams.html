5 · AxiToAvmm FSM

The AxiToAvmm module converts AXI4 transactions to Avalon-MM waitrequest-mode transactions. Write has priority over read in S_IDLE. All ready/valid handshakes are single-cycle pulses.

stateDiagram-v2 [*] --> S_IDLE : reset S_IDLE --> S_WRITE : awvalid AND wvalid\nassert awready, wready\nlatch addr, wdata, id\navmm_write=1 S_IDLE --> S_READ : arvalid (write takes priority)\nassert arready\nlatch addr, id\navmm_read=1 S_WRITE --> S_WRITE_RESP : avmm_waitrequest=0\navmm_write=0\nbvalid=1 S_WRITE_RESP --> S_IDLE : bready=1\nbvalid=0 S_READ --> S_READ_RESP : avmm_waitrequest=0\navmm_read=0\nlatch rdata\nrvalid=1, rlast=1 S_READ_RESP --> S_IDLE : rready=1\nrvalid=0 note right of S_IDLE AXI ID echoed on response channels. bresp / rresp always OKAY (0x00). Single-beat only; burst length accepted but only first beat forwarded. end note

6 · JesdSyncController FSM

Two independent identical FSMs (Group 0: links 0+1; Group 1: links 2+3) each wait for all assigned links to assert frame_ready, then align the data release to an LMFC boundary for deterministic latency. Group 1 is permanently stuck in ST_WAIT_LOCK in Phase A (links 2 and 3 are tied low — no second AD9176).

LMFC-aligned release guarantees deterministic transport latency. end note note right of ST_ERROR sync_err[n] sticky latch set. HPS clears via W1C JESD_SYNC_ERR. 7 · DataSrcMux — Source Switching Logic

Double-buffered LMFC-aligned source switching. The shadow register tracks the requested source; it is committed to the active source only on LMFC boundaries (and, for FIFO, only when the fill level meets the pre-fill threshold).

8 · SineWaveGen NCO Pipeline

Three-stage pipeline inside SineWaveGen. Stages 1 and 2 are registered; stage 0 is combinational. Total output latency from phase accumulator update to valid sample output is 2 link clock cycles. All four converters execute the same pipeline in parallel.
